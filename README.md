# EDXRF Elemental Classifier

Machine Learning Classification of Elemental Compositions

## Quick Start

bash
pip install -r requirements.txt
streamlit run app.py


## Model Performance

- Accuracy: 86.5%
- Sensitivity: 68.8%
- Specificity: 94.4%

## Deployment

1. Push to GitHub
2. Deploy on share.streamlit.io
3. Done!
